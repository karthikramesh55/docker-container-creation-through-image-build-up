# kata-docker-operations
A kata for docker image build-up + container creation through a Dockerfile
- Configuring a base image
- Creating a requirements.txt file for naming the dependencies
- Packaging the source code for a serving application + the aforementioned requirements.txt file
- Configuring the installation of the dependencies on the machine of the image user
- Exposing the parent port to a target port for running the serving application on the latter
- Configuring the execution of the serving application through CMD ["...", "..."]
